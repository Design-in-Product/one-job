## Janus's Dispatch research: real precedent, doesn't transfer to this shape

Janus found the pattern — **Dispatch** (DinP's original Cowork
coordination agent) and **Archie** (VA Ops) both do this, documented in
`~/Development/dispatch/PROTOCOLS.md`. But it's not a live handoff: it's
async and filesystem-based — Cowork and the Code agent share **one local
clone on the same Mac**, Cowork commits locally (no push credentials of
its own), and the Code agent pushes on its next fire, verified by memo or
by finding the unpushed commits directly.

Janus's own caveat, independently confirmed by my PAT test today: this
depends on a shared filesystem clone, which a cloud Cowork session with a
network-less device bridge doesn't have. Janus had already flagged the
scoped-PAT approach as the better fit for this agent's shape — my test
today found that one blocked too, for a different, structural reason (see
the memo filed this session).
