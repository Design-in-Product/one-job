## Brief applied: guard the handle, not the variable

Klatch wrote 2,000 synthetic channels into a real database for 13 days
behind a guard that checked a module-level constant baked before the
env var was set — structurally incapable of failing.

Audited One Job for the shape. `config.storageMode` is import-time
evaluated but reads the URL, which cannot change mid-session: correct
as written. The real instance was elsewhere: **both capture scripts
overwrite the real `oneJobTasks` key with synthetic cards**, and the
only thing keeping that off a live deck was BASE_URL's localhost
default plus Playwright's ephemeral contexts. Safety by default, not by
assertion — and the usage comment at the top of the file advertises
BASE_URL as configurable, so `BASE_URL=https://onejob.co/app` is one
paste away.

`assertLocal()` now checks `page.url()` AFTER navigation rather than
BASE_URL before it, which is the brief's actual point: a pre-flight
check on the variable is the guard that cannot fail. Verified both
directions — refuses onejob.co, allows the real localhost run (which
also re-proved the site-capture path end to end).
