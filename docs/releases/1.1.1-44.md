# 1.1.1 (44) — the open card, refined; Markdown; moving decks

**Follows 43** (2026-10-13), which passed on 10-16. 44 carries
everything in 43. Every display rule in this build, with who decided
it and why: `docs/CARD-DESIGN.md`.

## What's new in 44

**The title and description look editable.** Each sits in a faint
inset box. Tap either to edit it. The box deepens while you type.

**The description is only as tall as its text.** The deck inside a
card is now one fixed size on every card, a third bigger than in 43.
Long text scrolls inside the card, and the bottom edge fades when
there is more.

**Editing the description gives you the whole card.** While you type,
the description fills the card below the title. The deck inside comes
back when you're done.

**Markdown shows as formatting.** Text from GitHub or Todoist with
headings, **bold**, lists, code or links shows formatted in the open
card. Links open when you tap them. The card face and the Done list
show plain text. When you edit, you see the text as typed.

**A long text no longer stretches a card in the Done view.**

**Decks:** a deck can be deleted once it's empty. "Move all cards to
another deck…" empties it. "Move this deck into a card…" puts a whole
deck inside an existing card or a new one. These are in the long-press
menu when you have more than one deck.

## What to test

1. Tap a card. The title and description should each sit in a faint
   box. Tap the description, type, and close the card: the change
   should be saved.
2. Edit the description of a card that holds a deck. The description
   should fill the card while you type, and the deck should come back
   when you tap elsewhere.
3. Open two cards, one with a short description and one with a long
   one. The deck inside should be the same size on both, and the long
   text should scroll.
4. Add a card whose description has `## A heading`, `**bold**`, a list
   and a link. In the open card it should be formatted, and tapping the
   link should open it. On the card face it should be plain text.
5. With two or more decks, long-press and use "Move all cards to
   another deck…", then delete the emptied deck. Every card should be
   in the other deck.

## Not in this build

Cards inside a card's own deck still can't be edited.
