# 1.1 (39) — placement ruled: external cards never usurp the top

**Follows 38 same-day**, after the first tester report.

## What's new in 39

**Cards added via Shortcuts join the deck BEHIND your current job** —
deliberately. The top card is the thing One Job protects; an external
add shouldn't be able to interrupt it. (Build 38 did this by accident
and inconsistently; 39 does it on purpose, tested. Multiple queued
adds land in arrival order, still behind the top. An empty deck has no
focus to protect — the arriving card is simply the deck.)

Cards you add yourself, in the app, still take the top — you chose
them.

## What to test (differences from 38's list)

1. With a deck going, add via Shortcuts → open One Job → your top card
   is UNCHANGED; the new card is right behind it.
2. Queue 2–3 adds without opening the app → they're behind the top in
   the order you added them.
3. Siri retest still stands: launch once, wait a few minutes, then
   "Add a card to One Job."
4. Everything from 38's list that you haven't poked yet (hostile
   titles, sub-tasks).

## Known quirks found in the field (2026-09-17, Xian's Siri testing)

**1 · A Siri-dictated title can arrive ALL CAPS.** Reported from real
use. Ruled out on our side: the card title is rendered with no
text-transform (the only `uppercase` class in TaskCard is the deck-name
chip), and the intent passes the string through with nothing but a
whitespace trim. So the capitalisation is arriving from Siri's
dictation, and the open question is whether it always does, or only for
certain phrasings. **Not fixed, deliberately** — auto-lowercasing user
input is its own bug ("NASA", "URGENT"), so the fix depends on knowing
the exact pattern. See the ask in the rollup.

**2 · Siri only asks for the title; description and sub-tasks are not
a Siri path.** This is Apple's rule, not our omission: Siri prompts for
required parameters only, and both of those are optional by design (a
voice capture should be one breath, not an interview).
**They are fully available in the Shortcuts app** — tap the Add Card
action to expand it and both fields are there, which is also how an
importer like Teresa's passes them. Worth saying out loud in the tester
notes because "I couldn't find it" is what actually happened.
